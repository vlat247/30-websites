## Projects

### 1. Vision (`first-try`)
**Vision** is a modern, immersive landing page built with Next.js, focusing on premium design aesthetics, fluid typography animations, and a captivating user experience.

**Outstanding Feature:** 
An **Interactive WebGL ASCII Video Background** that dynamically responds to scroll progression and cursor movement. It delivers a unique, cinematic visual experience by blending custom shaders, ASCII art rendering, and seamless Framer Motion scroll animations.
